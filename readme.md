# 定向模糊测试

## 1.目标函数接口恢复

给定目标内核函数，在必要前置状态已满足的条件下，恢复能够发起目标函数执行的 Linux 调用接口，提取用于选择相关接口、匹配目标对象及选择目标处理分支的关键资源参数。

1. 恢复能够到达目标函数的linux调用接口
   - Socket proto_ops 分发，如识别 connect、sendmsg、bind 等操作。
   - VFS file_operations 分发，如识别 read、write、ioctl 等操作。
   - 协议分发表、驱动操作表和回调注册：识别间接调用及其绑定关系
   - 识别用户操作与其提交的工作任务、后续回调之间的触发关系
2. 恢复能够到达目标函数的关键资源参数
   - 接口选择参数：协议 family、socket 类型、协议号、channel、设备路径
   - 对象匹配参数：VID/PID、设备或板卡名称、驱动匹配条件
   - 操作选择参数：ioctl 命令、消息类型、子命令、选项及相关 flags
   - 辅助结构标识：用户接口结构及相关字段名称
